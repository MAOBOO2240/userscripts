# MAO BOO 油猴整合包

把常用的油猴腳本整合成一支，每個功能都能在 Tampermonkey 選單裡個別開關，並會自動更新。

**安裝／更新：** <https://raw.githubusercontent.com/MAOBOO2240/userscripts/main/maoboo.user.js>
（裝好 Tampermonkey 後點這個連結，按「安裝」即可）

**手機只要漫畫翻譯：** 另外有一支 [手機版漫畫翻譯](#手機版漫畫翻譯)，只有漫畫翻譯，介面為手機調整過：
<https://raw.githubusercontent.com/MAOBOO2240/userscripts/main/manga-mobile.user.js>

## 功能

| 功能 | 作用網站 | 說明 |
|---|---|---|
| 影片快轉 | 所有網站 | Ctrl + ← / → 倒退、前進 87 秒（秒數和修飾鍵可改），打字時不會誤觸 |
| 短影片自動下一部 | YouTube、Instagram、Facebook | Shorts、Reels 播完馬上跳到下一部，不會先重播開頭；切到其他分頁也會繼續播 |
| 影片音量記憶 | Threads、X、Instagram、Facebook | 每個網站各記住一個音量（預設 Threads、Instagram、Facebook 10%，X 1%），之後每支影片都用這個音量，不會突然 100%，網站自己的音量條也會顯示一樣的音量。在網站的音量條或設定面板調都可以（設定面板可以直接打數字，或用滑鼠滾輪調）。直接打開 video.twimg.com 的影片網址時設成指定音量（預設 5%） |
| 漫畫翻譯 | 漫畫網站（Alt+T 任何網站） | 英文、日文、韓文漫畫翻成繁體中文，用白底蓋住原文；滑到圖片上按「翻譯」，或按 Alt+T 翻譯整話 |
| 簡體轉繁體 | 簡體中文網頁 | 打開簡體網頁（小說、B 站、知乎等）時自動轉成繁體，之後載入的內容也會轉；輸入框、程式碼、日文網頁不會動 |
| X 影片下載按鈕 | X | 推文旁的下載鈕，用 cobalt.tools 下載；按住 S 點圖片時不會跳出 X 的分享選單 |
| LINE 貼圖下載 | LINE Store | 靜態圖打包 ZIP；動態圖直接在 LINE 頁面轉成去背 GIF 再打包（不需要另開網頁） |
| 隱藏推薦內容 | Facebook、Threads | 動態裡的「贊助」、推薦貼文、「你可能認識的朋友」、「為你推薦」的帳號直接隱藏 |
| 網址追蹤參數清除 | 所有網站 | 清掉 utm_、fbclid、gclid 等，以及 YouTube／Spotify 的 si、X 的 s 和 t、Threads 的 xmt |
| 手機版自動轉電腦版 | m. 網址 | m. 開頭的網址自動換成 www.，維基百科的 zh.m. 也會轉 |

## 漫畫翻譯

- **用法：** 在支援的網站把滑鼠移到漫畫圖片上，右上角會出現「翻譯｜整頁」。按「翻譯」只翻這張；按「整頁」或 Alt+T 會翻譯這一話的每張圖：畫面上的先翻，下面還沒捲到、網站還沒載入的圖也會先下載先翻好；翻頁式的閱讀器會先翻後面幾頁，換頁要重新載入的網站，下一頁會自動接著翻。再按一次 Alt+T 可以暫時看原文。手機上是角落的「譯」按鈕。
- **翻譯方式（設定面板）：**
  - **快速（預設）：** 瀏覽器自己認字（PaddleOCR，英文、日文直排、韓文都認得很準），再用 Google 翻譯，畫面上很快就有譯文；有 Gemini 金鑰時，再把認出來的文字（不送圖片）交給 Gemini 依前後文修正認錯的字和不順的翻譯。畫面上的圖單獨先送、一張修好就換上；後面預先翻好的圖很多張合成一次送，一整話只用幾次，很省次數；次數用完也照樣有 Google 的翻譯。
  - **精準：** Gemini 直接看圖找字、翻譯，認字最準，但每張圖都會用到次數，免費額度可能翻不完一話。
- **譯文的排法：** 會先找出對話框（被外框圍起來的白色或淺色範圍），同一個框裡的字合成一段翻、用同一個字級；白底照對話框的形狀（橢圓、方框）蓋滿，原文不會漏出來。兩個連在一起、中間沒有外框的對話框（8 字形）會分開翻。又高又窄的對話框用直排（由上到下），日文漫畫原本是直排的也用直排；譯文的字不會比原文大太多。沒有對話框的字（旁白、畫面上的字）照原本的位置蓋。
- **被切開的句子：** 長條漫畫常被網站切成好幾張圖。剛好被切在兩張圖中間的字或對話框，會把兩張圖接縫附近拼起來重新認字、整句一起翻（Gemini 修正也是送整句）；兩張圖緊貼在一起時，譯文跨兩張圖畫成一個框，中間有空隙時譯文放在比較大的那一半、另一半只蓋白底。
- **狀聲詞：** 預設不翻（BAM、DUN、TILT、NOD 這類效果字、動作字，日文的ドン、ゴゴゴ），原圖保持原樣；設定面板的「狀聲詞」可以改成「也翻」。
- **進度：** 整話翻譯時角落有一條狀態列和進度條，顯示翻到第幾張、正在做什麼（下載辨識資料、認字、Gemini 修正…）；正在翻的圖上也會標出進度。超過 30 秒沒有進度會顯示「好像卡住了」，按「重試」重新開始。狀態列會避開網站自己的按鈕，翻完會收起來，滑鼠移到那個角落附近會再出現（手機上按「譯」叫回來）。
- **自動翻譯：** 設定面板裡可以改成「打開漫畫就自動翻譯整話」（預設關閉）。
- **Gemini 金鑰（建議）：** 到 [Google AI Studio](https://aistudio.google.com/apikey) 免費申請，貼到設定面板的「Gemini 金鑰」，按「測試」。金鑰只存在你的瀏覽器裡。
- **不會收費：** 每個 Gemini 模型每天有免費額度，用完會自動換下一個模型；全部用完就改用免費模式，隔天（台灣時間下午）自動換回 Gemini。只要沒有自己在 Google 開啟付費，就不會被收費。
- **認字和翻譯：** 瀏覽器裡的文字辨識用 PaddleOCR（PP-OCRv6 模型，在背景執行，不會讓網頁卡住）。第一次在一個網站使用時要下載辨識模型（英文約 10 MB；日文、韓文另外多 13～21 MB），之後存在那個網站的瀏覽器資料裡，不用再下載；載入失敗時會自動改用 Tesseract.js。翻譯用 Google 翻譯（跟 Chrome 右鍵翻譯同一套；連不上時改用 Chrome 離線翻譯）。
- **支援的網站：** 預設有 kingofshojo.com、ezmanga.org、comix.to、telltome.net（G站、包子漫畫）、nhentai.net、Naver／Kakao 等韓國條漫網站，可以在設定面板或選單裡增減。
- **跨網域權限：** 第一次在新的圖庫網域翻譯時，Tampermonkey 可能會問要不要允許連線，請選「永遠允許此網域」或「永遠允許所有網域」，不要選「允許一次」。
- 翻過的圖會記住（最多 400 張），重看不會再花額度；一個字都沒認到的不記住，下次打開會重新認。
- **回報問題：** 翻不出字、譯文沒蓋上去這類問題，翻譯中打開 Tampermonkey 選單按「複製診斷資訊」：會實際測一次文字辨識和 Google 翻譯（10～40 秒），再按「複製」貼給開發者就能幫忙查。內容只有網頁、圖片和測試結果的狀態，不含金鑰、完整網址和漫畫裡的文字。

## 手機版漫畫翻譯

整合包裡的漫畫翻譯單獨拿出來的版本，只有漫畫翻譯，給手機用（翻譯方式、設定都跟整合包一樣）。

**安裝／更新：** <https://raw.githubusercontent.com/MAOBOO2240/userscripts/main/manga-mobile.user.js>

- **iPhone／iPad：** 從 App Store 安裝 Tampermonkey（付費 App），到「設定 › App › Safari › 延伸功能 › Tampermonkey」（iOS 17 以前是「設定 › Safari › 延伸功能」）打開，「所有網站」選「允許」。再用 Safari 打開上面的連結，按「安裝」。
- **Android：** Chrome 不能裝擴充功能，請用 Microsoft Edge 或 Firefox：在瀏覽器的「擴充功能」（Firefox 是「附加元件」）裡安裝 Tampermonkey，再用同一個瀏覽器打開上面的連結安裝。
- **用法：** 在支援的漫畫網站打開一話，左下角會出現圓形的「譯」，點一下就翻譯整話。翻譯時下方有一條狀態列：「顯示原文」切換原文和譯文、「設定」打開設定、× 收起狀態列（翻譯不會關掉，譯文照樣留在圖上）。翻完狀態列也會自己收起來，再點「譯」叫回來。要關掉翻譯、恢復原文：在 Tampermonkey 選單按「關閉漫畫翻譯（恢復原文）」。「譯」和狀態列會避開網站自己的按鈕，閱讀器的換頁列（＜ 2 of 62 ＞）捲到畫面底部時，會自動換到畫面上方。
- **其他網站：** 打開瀏覽器的擴充功能（iPhone 是網址列的擴充功能圖示）› Tampermonkey，選單裡按「翻譯這一話的漫畫」；或按「在這個網站顯示翻譯按鈕」，之後這個網站也會出現「譯」。
- **設定：** 設定面板從畫面下方滑上來；按鈕、開關、輸入框都放大成手指好按的大小，輸入框的字是 16px，iPhone 點進去不會把整個畫面放大。
- **沒有手機版排版的網站：** 整頁縮小顯示時，「譯」、狀態列、設定面板和圖上的進度標籤會自動放大回正常大小；用兩指放大縮小時也會跟著調整。
- **Gemini 金鑰：** 金鑰只存在那個瀏覽器裡，電腦上填過的話，手機上要再填一次。
- **第一次使用：** 每個網站第一次翻譯時要下載文字辨識模型（英文約 10 MB），建議連 Wi-Fi；之後存在瀏覽器裡，不用再下載。手機認字比電腦慢一點，畫面上的圖會先翻。
- **翻譯被擋下：** 手機網路常常很多人共用同一個網路位址，Google 免費翻譯有時會暫時擋下（HTTP 429）；這時會自動改用微軟翻譯，狀態列會寫「微軟翻譯」。
- **整合包也裝了的話：** 同一個瀏覽器兩個都裝時，只會有一個在翻譯，不會出現兩個「譯」、也不會翻兩次。手機上建議只裝這一支。
- **版本：** 手機版有自己的版本號和更新紀錄，跟整合包分開發布：手機版更新時，電腦上的整合包不會跟著更新；整合包更新時，手機版也不會。
- **更新：** 會自動檢查，有新版本會在下方跳出通知，按「更新」就好。

**手機版更新紀錄**

- **1.5.11**：狀態列右邊的 × 改成只收起狀態列（翻譯照常進行、譯文留在圖上），按「譯」再叫出來；要關掉翻譯用選單的「關閉漫畫翻譯（恢復原文）」。排版：斜斜錯開、連在一起的兩個對話框會分開翻譯、各放各的譯文（之前會併成一大塊直排、字很小，另一塊只剩白底）；英文、韓文漫畫的譯文維持橫排，只有框非常高窄才改直排；疊成階梯狀的旁白方框，白底和譯文不會再跨到另一個方框、蓋掉它的外框；TAK、TUK、KWANG 這類用拼音寫的狀聲詞不翻。之前用「快速」翻過的圖，再打開時會重新翻一次、套用新的排版（「精準」翻過的沿用）

## 隱藏推薦內容

- **收起來的：** Facebook 首頁的「贊助」廣告、還沒追蹤的粉專和還沒加入的社團的推薦貼文（名字旁邊有「追蹤」或「加入」）、「你可能認識的朋友」；Threads 的「為你推薦」帳號和贊助貼文。Facebook 只整理首頁，社團、個人頁面不動。
- **收起來的樣子：** 預設完全隱藏，看不到任何痕跡。想知道收了哪些，可以在設定面板改成「留一行字」：例如「已收起「贊助」：店家名稱（點一下打開）」，好幾則連在一起時併成一行「已收起 5 則：推薦貼文 3、贊助 2」，點一下全部打開。
- **要收哪些：** 設定面板裡 Facebook、Threads 各自可以選「收贊助和推薦」、「只收贊助」或「不收」；Facebook 還可以連 Reels 一起收。

## 開關功能

- 點瀏覽器上的 Tampermonkey 圖示，整合包底下有「漫畫翻譯」和「短影片自動下一部」，前面會顯示【開】或【關】，點一下就切換，馬上生效。
- 其他功能都在「開啟設定面板」裡開關，也能調秒數、音量等設定。設定會同步到所有分頁。

## 自動更新

- 整合包 `maoboo.user.js` 和手機版 `manga-mobile.user.js` 各自有版本號，各自改版，互不影響。
- 兩個檔案都是從 `src/maoboo.src.js` 用 `node tools/build.js full` 或 `node tools/build.js manga` 產生的；手機版的版本號和更新紀錄在 `src/manga.json`。只發布其中一個時，另一個檔案不會動。
- 整合包每 30 分鐘會檢查一次，有新版本會在網頁下方跳出通知，按「更新」就會打開 Tampermonkey 的更新畫面。
- 也可以在設定面板下方按「檢查更新」立即檢查。

## 取代的舊腳本

安裝整合包後，請在 Tampermonkey 管理面板把這些舊腳本關掉或刪除，避免重複執行：

- 快捷鍵+左右跳過 87秒
- YouTube Shorts 自動下一部
- 通用手機版自動轉電腦版 (m. to www.)
- X.com (Twitter) 影片下載器 & 自動 1% 音量
- X (Twitter) 直連影片自動音量控制
- 通用網址追蹤參數清除器
- LINE Store 貼圖下載器
